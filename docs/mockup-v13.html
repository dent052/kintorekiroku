アイコン案 v13 ─ 5案

いまのアイコン（オレンジに黒のダンベル）は、角を丸めた絵を「端まで描いてある絵（maskable）」として登録していたため、Android が丸く切り抜いたときに角の透明部分が白く出ていた。どの案も四角の端まで色で塗り、印は中央の安全な円（直径80%）の中に収めるので、白い縁は出ない。色はアプリと同じ藍・朱・白にそろえる（いまのオレンジはアプリの中に一度も出てこない色）。

既存アプリから集めた事例（App Store のアイコン、2026-10-23 取得）
  • Strong：濃紺の地に、白い棒と青い重りのダンベル。1色の差し色だけ。
  • Hevy：黒地に白の太い線で H とダンベルを1つの形にまとめた印。
  • Stronglifts 5x5：赤地に白の、縦に並んだ重りだけを抜き出したバーベル。
  • Setgraph：ダンベルの重りが頭文字 S・G になっている。
  • Fitbod・Caliber・JEFIT・Boostcamp：頭文字を幾何学的に崩した印（モノグラム）。
  • Apple Fitness：器具ではなく「進み具合（リング）」そのものを印にしている。
  • Nike Training Club・Gymshark：ブランドのロゴ。

共通する型：①地は1色で端まで塗る ②印は1つ、太い線で、小さくても形が読める ③色は2色まで ④器具・頭文字・進み具合のどれかを印にする。下の5案はこの型に沿って、器具（案D・C）・頭文字（案A）・進み具合（案B・E）からそれぞれ作った。

案A　朱の印「筋」頭文字（モノグラム）の型

藍の地に、朱の角印で「筋」。アプリの見出しと同じ書体・同じ2色なので、開いたときに一続きに見える。日本語の一文字の印は、海外のどの事例とも被らない。弱み：器具の形が無いので、一目で「筋トレ」と分かるのは漢字を読んだとき。

案B　階段と朱の点進み具合の型

記録の画面の「階段グラフ」と「ライン」をそのまま印にした。点線＝ライン、それを越えた段の先に朱の点＝突破。このアプリだけの仕組みを表す印。Apple Fitness のリングと同じ考え方。弱み：器具の形が無く、初見では記録・家計簿系にも見える。

案C　バンド器具の型（自宅・バンド）

朱のループバンドを白い手が上下に引いている形。ダンベルではなく、実際に使っているバンドの印。自宅・自重＋バンドというこのアプリの前提がそのまま出る。弱み：小さいと「朱の角丸の枠」に見えやすい（下の 24px を見てほしい）。

案D　藍と朱のダンベル器具の型（定番）

いまのアイコンの形を残して、色をアプリに合わせて端まで塗った一番手堅い案。一目で筋トレと分かる。弱み：Strong（濃紺に青いダンベル）とかなり似る。並んでも区別はつくが、個性は5案で一番弱い。

案E　ラインを越える進み具合の型

朱の地に、白い一本線（ライン）を藍の山形が下から突き抜ける。「前回＋1を越える」という毎回の目標を一つの動きで表した。ホーム画面で一番目立つ色。弱み：朱が地なので、アプリを開いたときの藍の画面との一続き感は案A・Bより弱い。

おすすめ：案A（朱の印「筋」）

アプリの中の色・書体と完全に一続きになり、事例のどれとも被らず、24px でも「藍の中の朱い四角」として見分けられる。器具の分かりやすさを優先するなら案D、アプリの仕組みを推すなら案B。

技術メモ：採用した案は 512px と 192px の PNG（文字は画像にするのでフォントに頼らない）に書き出し、manifest には purpose: "any" と purpose: "maskable" を別々に登録する（いまの "any maskable" 1枚は Chrome が非推奨としている）。
