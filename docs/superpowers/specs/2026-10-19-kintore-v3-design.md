# 筋トレ記録アプリ 設計書 v3（画面のゼロベース再設計）

日付: 2026-10-19 / 状態: 承認済み（画面イメージ `docs/mockup-v6.html`）
前提: 仕組み（ライン、コーチ便、記録データ、GitHub 同期）は v2 のまま。**画面と操作はこの文書がすべて置き換える**（v1/v2 の画面・タブ・ドックの記述は無効）。

## 1. 原則（守れていなければ不合格）

1. **見る場所は白、押す場所は藍。** 画面は上の「紙」（`.see`、背景 `--paper`）と下の「板」（`.press`、背景 `--ai`）に分かれる。**押せるもの（button / a / select / input / textarea / 目盛り）は必ず板・シート・設定画面（いずれも藍）の中にある。** 紙の上には1つも置かない
2. **画面そのものは絶対にスクロールしない。** 紙と板の高さの合計は表示領域ちょうど。紙の中身が多いときは紙の中だけがスクロールする。板は常に全部見える
3. **主な画面は2枚：「今日」と「成長」。** 左右スワイプで行き来する。トレーニングと設定は、画面全体を使う専用モード
4. 色は藍・朱・白（＋その間のグレー）だけ。箱で囲まない、影を付けない。区切りは細い線と余白

## 2. デザイントークン

```
--paper   #F6F7F9   紙の背景
--ai      #1C2B4B   板・シート・設定の背景、紙の上の文字色
--ai2     #26375C   板の上の目盛りの帯、選ばれていないチップの下地
--shu     #D03C22   主ボタン（白文字 4.8:1）、紙の上の朱の数字
--shu-ai  #FF6A4D   板の上の朱（ラインの点線、超えた目盛り。藍の上 5.0:1）
--mute    #5E6B82   紙の上の補助文字（5.0:1）
--mute-ai #8FA0BF   板の上の補助文字（5.3:1）
--hair    #DDE2EA   紙の上の区切り線
```
書体：数字 `Barlow Condensed`（600/700）、日本語 `Zen Kaku Gothic New`（500/700/900）。Google Fonts から読み込み、Service Worker でキャッシュ。
板の上辺は角丸 26px。主ボタン（`.go`）は朱・白文字・角丸 18px・高さ 64px。副ボタン（`.sub` の中）は文字＋下線 1.5px `--mute-ai`、高さ 44px 以上。チップは角丸 22px、選択中は白地に藍文字。

## 3. 画面の構成

```
.app (position:fixed; inset:0; 縦に並べる)
 ├ .see    紙（flex:1; overflow-y:auto）
 └ .press  板（flex:none）。最下段に .pager（今日 / 成長）※トレーニング・設定モードでは pager なし
dialog.sheet  下から出るシート（藍）。閉じるは「閉じる」ボタン
```
`index.html` の構造はこの形に作り直す（v2 の `#view` `#dock` `.tabs` `#timer` は廃止）。

### 3.1 スワイプ
- 今日・成長：紙または板の上で左右スワイプ（横 60px 以上、横 ≥ 縦×2、700ms 以内）→ 2枚を切り替え。`.pager` の文字をタップしても切り替わる
- トレーニング：同じスワイプで前／次の種目
- **目盛りの上ではスワイプ切り替えをしない**（目盛り操作と区別するため）
- 切り替え時、紙の中身が 200ms で横からスライド（`prefers-reduced-motion` では無し）

## 4. 今日（起動時の画面）

**紙**（上から）
1. 日付 `10月20日 火曜`（左、`.k`）と `通算 48 日`（右）
2. `今日のライン ・ {メニュー名}`
3. メニューの各種目の行（区切り線）：左に種目名、その下に小さく補足、右に大きくラインの値
   - 補足：band は `{今のバンド名} ・ `、続けて `前回 {1セット目の値}{秒} ・ 突破` / `・ あと{n}`（前回の結果）。記録なしは `初回`
   - 値：`line` が値を持てばその数字（time は `秒` を小さく付ける）。前回 short だった種目は**朱**、それ以外は藍
   - `base` は値の代わりに `初回`、`up` は `{next}へ` を値の位置に小さめ（28px）で
4. **新着**（下寄せ）：`新着 {未読数}` と、最新2件（コーチは `コーチ`、記録由来は `記録`、kind に応じた朱の小見出し＋本文1〜2行）。0件なら出さない

**板**
- `始める`（主ボタン）
- 副ボタン行：`メニュー変更` `軽めの日` `休む` `体重`
- `.pager`

**メニュー**：初期値は「前回と同じ」（今日より前の一番新しい light=false の session の種目、種目の並びは記録順）。`メニュー変更` のシートで テンプレート一覧 / 前回と同じ / 種目を選ぶ（複数選択→決定） を選べる。選んだメニューは `kintore:menu`（`{kind:'same'|'template'|'custom', templateId?, exerciseIds?}`）に保存。記録が1件もなければ「種目を選ぶ」が初期値。
**種目が1つもない**：紙に `まず種目を登録しましょう`、板に `種目を追加`（主）→ 設定モードの種目追加を開く。

`休む`・`体重` は v2 と同じ内容をシートで。`軽めの日` は今日のメニューを各1セットで開始。

## 5. トレーニング（専用モード）

**紙**
- 上端：進み具合のバー（種目数ぶんの短い線。済=朱、今=藍、未=`--hair`）と `n / m`
- 種目名（900、34px）、`前回 16 ・ 15 ・ 13`（band は `黒 16・15` のように負荷付き）
- 下寄せ：1セット目の前は `ライン` ＋ 朱の大きな数字（96px）。base/up/flat/down は v2 §3.5 の文言をこの位置に
- 済んだセットがあれば、`今日 18 ・ 16` のように並べる
- 最下部に `{n}セット目`
- **休憩中**は紙の中身が置き換わる：上に結果の帯（1セット目の完了時だけ。朱地・白文字。v2 §3.5 の大きな数字＋言葉＋小文字）、中央に休憩の円（残り時間 64px、円弧が減っていく）

**板**（上から）
- 休憩中だけ：副ボタン行 `+15秒` `休憩を終える`
- weight 種目だけ：`重さ` の小さな −／＋ 行（0.5kg）
- band 種目だけ：バンドのチップ行（弱い順、選択中は白地）
- 大きな値（76px）＋単位
- **目盛り**（§5.1）
- `完了`（主ボタン）
- 副ボタン行：`◀ 前の種目` `メモ・その他` `次の種目 ▶`（最後の種目では `次の種目 ▶` の代わりに `終了`）

`メモ・その他` のシート：メモ欄、`コーチに送る：オン／オフ`、`種目を追加`、`セットを追加`、`次の段階へ切り替え`（nextId があるとき）、`トレーニングをやめる`（終了と同じ）。

完了の動き：v2 と同じ（記録は即保存、休憩タイマー開始、最初のセットだけ結果判定、予定セットを使い切ったら同じ内容の次セットを自動追加）。休憩が0になったら `navigator.vibrate([300,100,300])` で紙を通常表示に戻す。

**終了後**：紙にまとめ（`今日の記録`、`ライン突破 2 / 3`、合計と前回差、出来事）、板に `今日へ戻る`（主）。

### 5.1 目盛り（このアプリの目玉）
- 横長の帯（高さ 66px、角丸 12px、背景 `--ai2`）。中央に白い縦線（現在値の位置）
- 1目盛り = reps は 1回、time は 5秒。目盛り間隔 30px。5の倍数（time は 25秒ごと）は長い目盛りと数字
- **ドラッグ**（pointer events）で左右に動かす。指の移動 30px で値が1目盛り変わる。値が変わるたびに `navigator.vibrate(5)`
- **タップ**：帯の左 1/3 で −1目盛り、右 1/3 で +1目盛り
- 範囲：reps 0〜200、time 0〜600秒
- **ライン**：ラインの値の位置に朱（`--shu-ai`）の点線の縦線と `ライン{値}` のラベル。**ライン以上の目盛りは朱**
- アクセシビリティ：`role="slider"`、`aria-valuemin/max/now`、`aria-label="{種目名} 回数"`（time は `秒数`）。キーボードの ←→ で ±1

## 6. 成長

**紙**
- `ラインの階段` と種目名（900、34px）
- **階段グラフ**：その種目の、記録がある各日について `line(data, id, その日)` が値を持つ点を、日付順に水平→垂直の段で結ぶ（SVG path の `H`/`V`）。負荷ごとに線の色を変える（今の負荷＝朱、それ以外＝藍）。負荷が変わった最初の点の下に `{バンド名}へ` / `{kg}kgへ` / `{種目名}へ`。点が2つ未満なら `記録が増えると、ここに階段ができる`
- 数字3つ：`今のライン`（今日の `line` の値、なければ `—`）、`突破`（1セット目が clear だった回数）、`累計`（totals）
- `12週間`：12マス（1マス＝1週。その週の日数 0 / 1–2 / 3以上 で 空 / 薄藍 / 藍）
- **体重**を選んだとき：階段の代わりに体重の折れ線（日々の点＋7日平均の線、v1 と同じ）、数字は `最新` `7日平均` `4週間前との差`

**板**
- チップ行（横スクロール可）：記録のある種目（data.exercises 順）＋ `体重`（記録があるとき）
- 副ボタン行：`記録を見る・直す` `新着` `設定`
- `.pager`

`記録を見る・直す` のシート：12週間のカレンダー → 日付を選ぶとその日の内容（セットごとの −／＋ と 削除、メモ、`この日の記録を削除`）。中身は v2 と同じ、見た目だけ藍のシートに。
`新着` のシート：新着の全件（v2 の mergeFeed、時刻順）。開いたら既読。

## 7. 設定（専用モード）
画面全体が藍（押すものしかない画面なので）。上から 種目 / バンド / テンプレート / 一般（休憩秒数） / GitHub 保存 / バックアップ / AIに相談。中身は v2 と同じ。最下部に固定の行：`戻る`（主ではない、副ボタン）と `＋ 種目` `＋ バンド` `＋ テンプレ`。編集画面も藍で、最下部に `保存`（主）`キャンセル` と必要なら `アーカイブ`/`削除`。

## 8. やらないこと
- 4つのタブ、v2 のドック、カードの箱、ボタンの影
- ± ボタンによる回数入力（重さの 0.5kg 調整だけは −／＋ を残す）
- 体の記録の独立した画面

## 9. 合格条件
`e2e/v3.test.mjs`（設計者が書いた受け入れテスト）がすべて通り、かつ設計者が全画面のスクリーンショットを `docs/mockup-v6.html` と見比べて差がないこと。テストを変更・削除して通すことは禁止。

## 10. 見た目の作り方（見本と実装のずれを防ぐ）
v2 では見本の CSS を捨てて言葉で実装させたため、余白・太さ・大きさ・細い線が抜け落ち、見本の魅力が消えた。v3 では：
- **`style.css` は設計者が見本（`docs/mockup-v6.html`）の CSS から作る。実装者は `style.css` を変更しない**（必要なら質問する）
- 実装者は下の部品名（クラス・属性）どおりの HTML を JS で出力し、動きをつなぐだけ
- 受け入れテストで主要な計算済みスタイル（色・書体・大きさ）を見本の値と照合する
- 設計者は見本と同じサンプルデータを入れたアプリを撮影し、見本と並べて確認する
