# 筋トレ記録アプリ 設計書 v6（セットの表・終わりの明示・直せる）

日付: 2026-10-20 / 状態: 承認済み（画面イメージ `docs/mockup-v9.html`）
前提: v5 を土台に、**ここに書いたところを置き換える**。それ以外（タブ、ホーム、種目を変える、カウンタ、休憩、ライン、データ形式）は v5/v4 のまま。

## 0. なぜ変えるか（利用者の指摘）
- 予定の3セットが済んでも、どこを押せばよいか分からない。完了を押したら4セット目が記録された（予定を使い切ると自動で次のセットを足す作りだった）
- 間違えたセットを消す手順が分かりにくい（`記録 → カレンダーで見る・直す → 日 → 削除`）。「カレンダーで見る・直す」という名前も分からない
- 累計ではなく、セットごとに何回できたかを見たい
- アーカイブが何のためか分からず、押したら戻せない
- 一般的な記録アプリ（Strong, Hevy など）の基本：セットの表（前回／今日）、予定のセットが済んだら次の種目へ、済んだセットはその場で直せる

## 1. トレーニング中の紙（v3 §5 の紙を置き換え。休憩中は v4 のまま）
上から：進み具合（v3 のまま）、種目名、`.prev` の1行、下寄せ（`margin-top:auto`）に**セットの表** `.sets`
- `.prev`：1セット目の前は `ライン {値}{秒} ・ 1セット目`。ラインに値が無ければ v3 の言葉（`初回` など）。1セット目が済んだら `ライン {値} ・ 突破` または `ライン {値} ・ あと{差}`
- `.sets`：見出し行 `.hd`（`セット` `前回` `今日` 空欄）、続いてセットの行 `.r`
  - 行の数＝max（予定のセット数、今日済んだセット数）。予定のセット数＝トレーニング開始時の予定（v3 の `goal`、軽めの日は1）
  - 列：番号、`前回`＝前回の同じ番号のセットの値（無ければ `—`）、`今日`＝済んだ値／今のセットはカウンタの値／未着手は `—`（`--hair` の色）、右端に済んだ印 `.ok`（藍の丸に白いチェック）
  - band／weight は `今日` と `前回` の値の後ろに小さく負荷（`黒` `20kg`）。time は数字のみ（見出しを `前回(秒)` `今日(秒)` に）
  - 1セット目の `今日` がライン以上なら朱（`.over`）
  - 今のセットの行は `.cur`（白地、藍の枠 2px、角丸 10px）
  - **済んだ行は押せる**（ボタン）→ §3 のシート
- 紙の上で押せるものは、済んだセットの行だけ（v5 §1 の許可リストに `.sets .r.done` を加える）

## 2. トレーニング中の板（v4 §3 を置き換え）
- **予定のセットがまだ残っている**：カウンタ（v4 のまま）、主ボタン `{n}セット目を完了`、最下段 `.nav`（v4 のまま）
- **予定のセットが済んだ**（済んだ数 ≥ 予定数）：カウンタを出さない。上に副ボタン `＋ もう1セット`（`.subgo`。押すと予定数を1増やし、カウンタが戻る。値は直前のセットと同じ）、主ボタン `次の種目へ ▶`（最後の種目では `トレーニングを終える` → まとめ）、最下段 `.nav`
- **完了しても次のセットを自動で足さない**（v3 の「予定を使い切ったら同じ内容の次セットを自動追加」を廃止）
- `.nav` の `次 ▶`／`終了` はそのまま（予定の途中でも移れる）
- `メモ` シートの `セットを追加` は廃止（`＋ もう1セット` と同じため）

## 3. 済んだセットを直す（シート）
- 見出し `{n}セット目を直す`。カウンタ（v4 と同じ部品・同じ増減・長押し）、band はバンドのチップ、weight は重さの −／＋（v3 と同じ）
- 主ボタン `保存`：記録を書き換えて保存（`save()`）。ラインの判定・まとめは保存後の値で計算される
- `このセットを消す`（朱の文字 `.danger`）：確認なしで消して保存し、トーストに `{n}セット目を消しました` と `元に戻す`（押すと同じ位置に戻す。トーストが消えるまで＝4秒）
- `閉じる`
- 休憩中でも開ける

## 4. 記録の種目画面（v5 §6 の種目を置き換え）
- 種目名、階段グラフ（高さを見本どおり低く：viewBox 316×120）、数字は `今のライン` と `突破` の2つ（**累計は外す**）
- その下に**日ごとのセット**の一覧 `.hist`（新しい日が上、全件。紙の中でスクロール）：左に日付 `10月20日 火`、右にセットの値を ` ・ ` でつなぐ（band／weight は負荷が変わるところで `黒 12・10` のように v3 の `前回` 表示と同じ書き方）、最後に小さく `{n}セット`。1セット目がその日のラインを突破していれば1つ目の数字を朱
- **日の行は押せる** → その日のこの種目のセットを直すシート（見出し `{日付} {種目名}`、セットごとの行。行を押すと §3 と同じ直すシート）
- 記録の一覧（v5 §5）の行の小さな文字も `累計` を外し `突破 {n}回 ・ 前回 {その日のセット}` に

## 5. 記録の一覧の名前
- `カレンダーで見る・直す` を **`日付から探す`** に改名（中身は v3 の12週間カレンダーと日の編集のまま）

## 6. 種目のアーカイブを廃止、削除は元に戻せる
- 種目の編集画面から `アーカイブ` ボタンを外す。`削除`（確認あり）は今までどおり内部では `archived: true`（過去の記録を残すため）
- 種目タブの `アーカイブ済みを表示` を廃止。代わりに、削除した種目があれば一番下に小見出し `削除した種目` と、その行（名前と `.pill` `元に戻す`）。`元に戻す` で `archived: false` にして保存
- 既存データの `archived: true` は「削除した種目」として出る（利用者が間違えて押したものもここから戻せる）

## 7. 見た目
`docs/mockup-v9.html` の CSS をそのまま使う（`.sets` `.hd` `.r` `.cur` `.ok` `.over` `.subgo` `.hist` `.danger` `.restore`）。

## 8. 合格条件
- 見本どおり。予定3セット：完了3回で `次の種目へ ▶` が主ボタンになり、記録は3セットのまま（4つ目が勝手に出来ない）
- 済んだ行を押して値を直す・消す・元に戻すができる。記録の種目画面の日の行からも直せる
- 削除した種目を元に戻せる
- `npm test` と `npm run e2e` が通る。原則テスト（v5）は §1 の追加を反映
