# 筋トレ記録アプリ 設計書 v9（コーチのタイムライン）

日付: 2026-10-21 / 状態: 承認済み（画面イメージ `docs/mockup-v12.html` 利用者 OK、2026-10-21「いいよ」）
前提: v8 を土台に、**ここに書いたところを置き換える**。v7 §0（記録を歪めない）は引き続き最優先。

## 1. 下のタブ
- 5つ：`ホーム`・`記録`・`コーチ`・`種目`・`設定`（この順）。コーチのアイコンは見本の吹き出し `<path d="M4 5h16v11H9l-5 4z"/>`
- 未読のコーチの投稿が1件以上あれば、`コーチ` に朱のバッジ `.badge`（数字。0なら出さない）
- コーチの画面の mode は `coach`（タブが出る mode に加える）

## 2. 未読
- 未読＝コーチの投稿（`kintore:posts`、kind が reply / weekly / finding / reading）のうち、id が `kintore:seen` に無いもの
- コーチのタブを開いて描いたとき、表示した投稿の id を `kintore:seen` に足す（v5 の `markSeen` と同じ。上限500も同じ）。その描画では未読の行に `.tw.unread`（薄い朱の下地）を付けたまま見せ、次に描いたときから消える
- バッジとホームのカードは、この「未読」だけを数える

## 3. コーチの画面（`.see.list`）
- 見出し `コーチ`（`.h1`）。その下にタイムライン `.tl`。**新しい順**（`Date.parse(at)` の大きい順。日付だけの `at` は その日の 0:00 として扱う）
- 並ぶもの：
  1. コーチの投稿：藍の丸 `.av` `コ`、名前 `コーチ`、時刻、右に種類のタグ `.tag`（reply＝`返信`、weekly＝`週のまとめ`、finding＝`発見`、reading＝`読み物`）。reply で `quote` があれば本文の上に引用 `.q`。`source` に http(s) の url があれば本文の下に出典カード `.src`（太字＝title、下に url のホスト名）。カードは リンク（新しいタブ、`noopener noreferrer`）
  2. 自分の書き込み（§4 の `messages[]`）：白の丸 `.av.me` `私`、名前 `自分`、時刻
  3. トレーニングのメモでコーチに送ったもの（`toCoach: true` で `note` が空でない session）：自分と同じ見た目、時刻の代わりに日付、その後ろに ` ・ トレーニングのメモ`
- 時刻：今日＝`今日 7:23`、昨日＝`昨日 21:30`、それより前＝`10月19日`（時刻なし）。日付だけの `at` は時刻を出さない（`今日`／`昨日`／`10月19日`）。書いた直後（1分未満）＝`いま`
- まだ何も無いとき：v5 の `.empty`、太字 `まだやり取りはありません`、本文 `下の欄からコーチに書けます。返事は翌朝 7:22 ごろ届きます。`
- 返事待ちの表示：最新の自分の書き込み（2・3のうち一番新しいもの）より新しいコーチの投稿が無ければ、その行のすぐ下に `.note` `返事は明日の朝 7:22 ごろ届きます`（いまが今日の 7:22 より前なら `返事は今日の朝 7:22 ごろ届きます`。次のコーチ便がいつかで決める）
- 画面を開いたら `fetchFeedback()` を呼ぶ（10分の間引きは今のまま）。`fetchFeedback` が新しい投稿を保存したとき、coach の画面でも描き直す

## 4. コーチに書く
- 板 `.press` の場所に `.compose`（見本の CSS）：1行の入力欄（`placeholder` `コーチに書く…`、`maxlength` 1000）と `送る`（朱）。入力欄は板の上にあるので原則テストに合う
- 空白だけなら `送る` は押せない（`disabled`）
- 送ると `state.messages` の**先頭**に `{ id: uid('m'), at: new Date().toISOString(), text }`（text は前後の空白を取る）を足して `save()`（GitHub 同期は今のまま 5 秒後）。入力欄を空にして描き直す。振動はしない
- データ形式：`messages` は配列。**無いデータ（古いデータ・読み込んだファイル）は `[]` とみなす**。`parseImport` の必須の配列には加えない。`messages` が配列でなければ `[]` に直す
- 書き込みの消去・編集は作らない

### 4.1 改行（2026-10-23 追記、利用者「コーチ便打つ時改行できない」）
- 入力欄は `textarea`（`rows=1`）。Enter は**改行**（送るのは `送る` ボタンだけ）。入力に合わせて高さが伸び、5行を超えたら欄の中でスクロール。送ったら1行の高さに戻る。見た目（色・角丸・余白・最小の高さ 44px）は今の入力欄のまま。`送る` は欄の下端にそろえる
- 改行はそのまま `text` に入れる（前後の空白だけ取る）。タイムライン・ホームのカード・コーチの投稿の本文は改行をそのまま表示する（`white-space: pre-wrap`。ホームのカードは2行で切るまま）

## 5. ホームのカード
- 今週 `.week` の下（`今日は休む` などの `.quick` の上）に、未読のコーチの投稿のうち一番新しい1件を `.card`（ボタン）：藍の丸 `コ`、`コーチ` と小さく `{時刻} ・ {種類}`、本文は2行で切る（`-webkit-line-clamp:2`）。押すとコーチのタブへ
- 未読が無ければ出さない。カードを出しただけでは既読にしない

## 6. 記録のタブの `新着`
- `新着 n` の丸ボタンとそのシート（`openNews`）は**廃止**（コーチのタブに一本化）。自分の記録の出来事（突破など）は記録・詳細の画面で見られるので、タイムラインには入れない

## 7. コーチ手順書（`coach/README.md` とデータ用リポジトリの `README.md`）
- reply の条件に `data.json` の `messages[]`（`id`・`at`・`text`）を加える：返信済みでない書き込みとメモを全部まとめて1件。`ref` に書き込みの id と session の id を入れる。`quote` は一番新しいもの

## 8. 合格条件
- 見本 `docs/mockup-v12.html` どおり（タブ5つ、バッジ、タイムライン、書く欄、返事待ちの表示、ホームのカード）
- 書いた書き込みがすぐ一番上に出て、`kintore:data` の `messages` に入る。空白だけでは送れない
- `messages` の無い古いデータで、どの画面もエラーにならない
- 未読の数がバッジに出て、コーチのタブを開くと次から消える。ホームのカードは未読の一番新しい1件、押すとコーチへ
- 原則テスト（押すものは板・シート・設定の板の上）が通る
- `npm test` と `npm run e2e` が通る
