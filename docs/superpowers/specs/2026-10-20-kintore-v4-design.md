# 筋トレ記録アプリ 設計書 v4（ホーム中心の行き来と左右カウンタ）

日付: 2026-10-20 / 状態: 承認済み（画面イメージ `docs/mockup-v7.html`）
前提: v3（`2026-10-19-kintore-v3-design.md`）を土台に、**この文書に書いたところだけ**を置き換える。色・書体・紙と板の原則・記録データ・ライン・コーチ便は v3/v2 のまま。

## 0. なぜ変えるか（利用者の指摘）
1. 今日の板に「メニュー変更〜体重」の横並び、その下に「今日／成長」の横の切り替え、成長には横スクロールのチップ。横の動きが2軸重なり、スワイプで何が動くか分からない
2. 「今日」と「成長」を同じ重さの2枚にしたので、今日がホームに感じられない
3. トレーニングからホームへ戻る道がない（終了するしかない）
4. 目盛り（ドラッグ）より、左右のカウンタで数えたい

## 1. 原則（v3 §1 の 3 を置き換え。1・2・4 はそのまま）
- **ホームが中心。** トレーニング・成長・設定はホームから行って、ホームへ戻る。画面を横に並べない（`.pager` 廃止）
- **戻る道は1つ。** トレーニング・成長・設定の板の**最下段の左端**に `⌂ ホーム`。Android の戻る操作も同じくホームへ
- **横スワイプの意味はアプリ全体で「種目を替える」だけ。** トレーニングと成長でだけ効く。ホームと設定では何もしない
- 押すものは板・シート・設定の藍の上だけ（v3 と同じ）

## 2. ホーム（v3 §4 を置き換え。`data-mode="today"` のまま）
**紙**（上から）
1. 日付と `通算 n 日`（v3 と同じ）
2. 見出し `.hello`：小さく `今日のメニュー`、その下に大きく（900、34px）メニュー名（`menuName()`）
3. 種目の行 `.ln`：左に名前と補足（v3 と同じ）、中央に**小さな階段** `.mini`、右にラインの値（v3 と同じ。前回 short は朱）
   - `.mini`：64×28 の SVG。`lineHistory(state, id)` の最後の 8 点を、左から等間隔・上下は最小〜最大で（全部同じ値なら中央の高さ）、`H`/`V` の段で結ぶ。線は藍 2.5px、塗りなし。点が2つ未満なら中身なし（列の幅は保つ）
   - `今日のライン ・ …` の行は無くす（見出しに移ったため）
4. 下寄せ（`margin-top:auto`）の `.feed`：
   - `今週`：月〜日の7マス `.week`（曜日の文字の下に角丸のマス）。その日に**セットが1つ以上ある**記録があれば藍（`.d`）、今日は朱の枠（`.t`、`.d` と同時もあり）、それ以外は `--hair`。数・連続は出さない
   - `新着 {未読数}` と最新 **1件**（v3 の表示のまま、2件→1件）。0件なら出さない

**板**
- 主ボタン `始める`。トレーニングの途中（`training` があり今日の日付）なら文字を `続きから` にし、押すと途中の画面へ戻る
- 副ボタン行 `今日の調整` `成長` `設定`
- 種目が1つもないときは v3 と同じ（`種目を追加`）

**今日の調整**（`dialog.sheet`、見出し `今日の調整`）：縦の行 `.row`（ボタン、左に名前・右に小さな補足）
- `メニュー`（補足 `{メニュー名} ›`）→ v3 のメニュー変更シート
- `軽めの日`（補足 `各1セットで始める`）→ 軽めの日で開始
- `休む`（補足 `今日は休みにする`）→ v3 の休むシート
- `体重`（補足 `記録する`）→ v3 の体重シート
- 最下部に `閉じる`

## 3. トレーニング（v3 §5 の板を置き換え）
**回数の入力＝左右カウンタ**（目盛り `.ruler` は廃止）
- `.counter`：左に `−`、中央に大きな値（84px）＋単位、右に `＋`。ボタン `.pm` は 84×84、角丸 18px、背景 `--ai2`
- 1回押すと reps は ±1、time は ±5秒。範囲は reps 0〜200、time 0〜600（端で止まる）。値が変わるたびに `navigator.vibrate(5)`
- **長押し**：押して 400ms 後から 100ms ごとに繰り返す。指を離す／外れたら止まる
- `aria-label`：`{種目名} 1回減らす`／`1回増やす`（time は `5秒減らす`／`5秒増やす`）
- **最初の値**：1セット目は、ラインが値を持てばその値。それ以外（2セット目以降、ラインが無いとき）は今と同じ（前回の記録からの初期値）
- **1セット目だけ**、値の下に `.lineon`：ライン以上なら `<b>ライン{n}</b> 突破`、届かなければ `<b>ライン{n}</b> まで あと{差}`（time は数字に `秒`）。値がライン以上の間は大きな値を朱（`--shu-on-ai`、`.over`）。ラインが値を持たないときは出さない
- 重さの −／＋、バンドのチップは v3 のまま（カウンタの上）

**最下段** `.nav`：`⌂ ホーム` `◀ 前` `メモ` `次 ▶`（最後の種目では `次 ▶` の代わりに `終了`）。`メモ` は v3 の `メモ・その他` シート（中身は同じ）
- `ホーム`：トレーニングの状態（今の種目・セット・休憩）を残したままホームへ。ホームの `続きから` で戻る
- スワイプで前／次の種目（v3 と同じ。カウンタの上でも、横スワイプなら種目移動でよい）

**終了後**：板の主ボタンを `ホームへ` に（押すとトレーニングの状態を消してホームへ）。

## 4. 成長（v3 §6 の板と切り替えを置き換え）
- 紙：`成長`（`.k`）、種目名（v3 と同じ）、その下に**点** `.exdots`（項目の数だけ 7px の丸、今の項目が藍、他は `--hair`）。以下 v3 と同じ
- 項目＝v3 のチップと同じ並び（記録のある種目＋体重）。**チップ行は廃止**
- 横スワイプ：左へ＝次の項目、右へ＝前の項目（端では何もしない）
- 板：副ボタン行 `記録を見る・直す` `新着`、最下段 `.nav`：`⌂ ホーム` `◀ 前の種目` `次の種目 ▶`（端では押せない）
- `設定` は成長から外す（ホームから）

## 5. 設定（v3 §7 の `戻る` を置き換え）
- 最下部の固定行の `戻る` を `⌂ ホーム` にし、行の左端に置く。押すと常にホームへ

## 6. 戻る操作（Android）
- ホームからトレーニング・成長・設定へ行くとき `history.pushState` で1段積む。`popstate` では、開いているシートがあれば閉じ、ホームへ（`go('today')`）
- 板の `⌂ ホーム` は、積んだ段があれば `history.back()`、なければ直接 `go('today')`（どちらでも同じ結果）
- 終了後のまとめ（summary）からも同じ

## 7. 見た目（`docs/mockup-v7.html` の CSS をそのまま使う）
`.hello` `.ln`（3列）`.mini` `.week` `.nav` `.nav .home`（家のアイコン SVG＋文字、白）`.counter` `.pm` `.lineon` `.exdots` `.row`。不要になった `.ruler` `.pager` `.nav3` の CSS は消す。`.chips` はトレーニングのバンド選びで使うので残す（見た目は v3 のまま）。

## 8. やらないこと
- 下に固定のタブバー、画面の横並び
- 連続日数・週の目標・回数の目盛り
- トレーニングの途中状態のアプリ終了後の復元（記録は完了ごとに保存済みなので失われない）

## 9. 合格条件
- 見本 `docs/mockup-v7.html` どおり（CSS の数値をそのまま）
- 押すものが紙の上に1つも無い（e2e の原則テスト）、画面がスクロールしない（390×844、360×640）
- `npm test` と `npm run e2e` が通る
