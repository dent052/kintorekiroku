# 筋トレ記録アプリ 設計書 v5（下のタブ・押せる一覧）

日付: 2026-10-20 / 状態: 承認済み（画面イメージ `docs/mockup-v8.html`）
前提: v4 を土台に、**ここに書いたところを置き換える**。色・書体・記録データ・ライン・コーチ便・トレーニング画面（左右カウンタ、休憩、まとめ）は v4/v3 のまま。

## 0. なぜ変えるか（利用者の指摘）
- 「今日の調整」「成長」は何が起きるか分からず押す気にならない。導線が気持ちよくない
- 種目を一度入れたら消せない・足せないように見える（操作が3段の奥にあった）
- 記録が無いときの成長画面が「成長／成長」と 0 だけで意味不明
- 原因：独自の決まり（押すものは藍の板だけ）を優先し、一般的なアプリの作法（アイコン＋文字の下タブ、見えている物を押せる、具体的な名前）から外れていた
- 利用者の意図：「一般的な作法はよい。全部を上に寄せるのはやめろ」

## 1. 原則（v3 §1・v4 §1 を置き換え）
1. **一般的な作法に従う。** 画面の切り替えは画面最下部の**タブ**（アイコン＋文字、今のタブは白文字＋朱の線）。一覧の行は押せる（右端に `›`）。戻るは左上の `‹ 戻り先` と Android の戻る
2. **主な操作は画面の下。** `始める` `完了` `＋ 新しい種目` `決定` などの主ボタン（`.go`）は、タブのすぐ上（タブが無い画面では最下部）。紙の上に置いてよい押せるものは、一覧の行、白地の丸いボタン（`.pill`）、左上の戻るだけ
3. **画面そのものはスクロールしない**（v3 と同じ。紙 `.see` の中だけがスクロール）
4. **ボタンの名前は具体的な動作か行き先。** 抽象的なまとめ言葉（「調整」など）は使わない
5. 横スワイプはトレーニングの種目移動だけ（他の画面では何もしない）

## 2. 骨組み
```
.app[data-mode]
 ├ section.see      紙
 ├ section.press    板（主ボタンがある画面だけ。無ければ空で高さ0）
 └ nav.tabs         タブ（ホーム／記録／種目／設定）。train・summary・編集画面では出さない
dialog.sheet        下から出るシート（v3 と同じ）
```
- モード：`today`（ホーム）`records`（記録の一覧）`detail`（記録の種目／体重の詳しい画面）`exercises`（種目）`settings`（設定）`train` `summary`、編集画面（種目・バンド・テンプレートの編集。タブなし、下に `保存` `キャンセル`。v3 の編集画面と同じ中身）
- `.tabs`：4つ均等。各項目はボタンで、24px の線のアイコン（`docs/mockup-v8.html` の SVG をそのまま）＋文字 11px。今のタブは `aria-current="page"`、白文字、上に朱の線（幅28px 高さ3px）。`detail` のときは「記録」が今のタブ
- v4 の `今日の調整` シート、`成長` モード、成長の `.exdots`・横スワイプ・`◀ 前の種目` `次の種目 ▶`、ホームの副ボタン行は**廃止**

### 2.1 戻る操作
- 前へ進む操作（ホーム以外のタブへ、詳しい画面へ、編集画面へ、トレーニングへ）で `history.pushState` を1段積み、`popstate` で1つ前の画面に戻る。開いているシートがあれば、まずシートを閉じるだけ
- 戻り先：詳しい画面→来た画面（記録の一覧かホーム）、編集画面→来たタブ、ホーム以外のタブ→ホーム、トレーニング→ホーム（`続きから` が出る。v4 と同じ）
- タブを押したときは、同じ画面を積み重ねない（タブ同士の移動は積んだ段を置き換える）

## 3. ホーム（`today`）
**紙**（上から）
1. 日付と `通算 n 日`（v4 のまま）
2. `.head`：左に v4 の `.hello`（`今日のメニュー`＋メニュー名）、右に `.pill` `✎ 種目を変える`（鉛筆アイコンは見本の SVG）→ §4 のシート
3. 種目の行（v4 の `.ln` に右端の `›` を足して4列。行全体が1つのボタン）。押すと、その種目の詳しい画面（`detail`、戻るは `‹ ホーム`）
4. 下寄せ：`今週`（v4 のまま）、その下に `.quick`：`.pill` `今日は休む`（v3 の休むシート）と `体重を記録`（v3 の体重シート）
- 新着はホームから外す（記録の一覧へ）

**板**：主ボタン `始める`／`続きから`（v4 のまま）。種目が1つもないときは `＋ 新しい種目`（種目の編集画面へ）

## 4. 種目を変える（シート、見出し `今日の種目`）
- 上に丸いボタンの行 `.chips2`（折り返し可）：`前回と同じ`、続けてテンプレート名。今のメニューの種類に当たるものが選択中（白地）。押すと、下のチェックがその内容に入れ替わる
- 種目のチェック一覧 `.check`（アーカイブしていない種目、`data.exercises` の順）：左に丸（選択中は白い丸にチェック）、名前＋小さく部位、右に小さく `ライン {値}`（time は `秒`）、値が無ければ `初回`、`up` は `{next}へ`。押すたびに入る／外れる。チェックを変えたらメニューの種類は「種目を選ぶ（custom）」になり、上の丸いボタンはどれも選択なし
- `＋ 新しい種目を作る`（朱の文字の行）→ シートを閉じて種目の編集画面へ。保存したらホームに戻り、その種目を今日のメニューに加える（custom、今の並びの最後）
- `軽めの日（各1セット）` の切り替え（`.toggle`）。オンにすると今日だけ有効（`kintore:light` に今日の日付を保存。日付が違えばオフ扱い）。`始める` はこれがオンなら軽めの日で開始
- 最下部に `決定`（主ボタン）。押すとメニューを保存（`kintore:menu`、v3 の形式）してシートを閉じる。チェックが0個のときは押せない
- 閉じる操作は v3 のシートと同じ（`閉じる` を `決定` の下に小さく）。決定せずに閉じたら何も変えない

## 5. 記録（`records`）
**紙**：見出し `記録`（900 28px、`.h1`）
- 種目の行 `.rec`（記録のある種目、`data.exercises` の順）：名前、その下に小さく `突破 {clearCount}回 ・ 累計 {totals}`（band は先頭に `{今のバンド名} ・ `）、小さな階段 `.mini`（v4 と同じ作り方）、右に今のラインの値（無ければ `—`、36px）、`›`。押すと詳しい画面（`‹ 記録`）
- 体重の行（体重の記録があるとき）：`体重`、小さく `7日平均 {値}kg`、`.mini` に最近8件の折れ線、右に最新の値、`›`。押すと体重の詳しい画面
- `12週間`（v3 の `.heat`）
- `.quick`：`.pill` `カレンダーで見る・直す`（v3 の記録シート）と `新着 {未読数}`（v3 の新着シート。開いたら既読）
- **記録が1件も無いとき**（セットのある記録も体重も無い）：見出しの下、紙の中央に `まだ記録がありません`（900 22px）と `1回トレーニングすると、ここに種目ごとの伸びが階段で出ます。`（14px、`--mute`）だけ。`新着` が1件以上あれば、その下に `.pill` `新着 {未読数}` だけ出す
- 板なし（タブだけ）

## 6. 詳しい画面（`detail`）
- 左上に `.back` `‹ 記録`（ホームから来たときは `‹ ホーム`）。押すと戻る（§2.1 と同じ）
- 種目：種目名（v3 の `.exname`）、v3 の階段グラフと数字3つ（`今のライン` `突破` `累計`）。12週間は出さない
- 体重：見出し `体重`、v3 の体重の折れ線と数字（`最新` `7日平均` `4週間前との差`）
- 板なし（タブだけ。「記録」が今のタブ）

## 7. 種目（`exercises`）
**紙**：見出し `種目`（`.h1`）
- 部位ごと（v3 の部位の順、種目がある部位だけ）に小見出し `.group`、その下に行 `.ex`：名前＋小さく種類（`exerciseTypes` の表示名）、`›`。押すと種目の編集画面（v3 の中身：名前・部位・種類・並べ替え・アーカイブ・削除。削除は確認あり）
- 最後に `アーカイブ済みを表示` の `.pill`（v3 のトグルと同じ働き）
- 小見出し `テンプレート`：テンプレートの行（名前＋小さく `{種目数}種目`、`›`）→ テンプレートの編集画面。最後に `.pill` `＋ テンプレート`
**板**：主ボタン `＋ 新しい種目` → 種目の編集画面（新規）

## 8. 設定（`settings`）
- v3 の設定から `種目` と `テンプレート` の節を除いたもの：`バンド`（`＋ バンド` を節の中に）、`一般`、`GitHub 保存`、`バックアップ`、`AIに相談`。見た目は v3 のまま（藍）
- v4 の最下段（`ホーム` `＋ 種目` …）は廃止。タブだけ

## 9. トレーニング・まとめ
- v4 のまま（タブなし、左下 `ホーム`、`続きから`、まとめの `ホームへ`）。`メモ` シートの `種目を追加` もそのまま

## 10. 見た目
`docs/mockup-v8.html` の CSS をそのまま使う（`.tabs` `.press.slim` `.head` `.pill` `.ln.tap` `.chev` `.quick` `.h1` `.rec` `.empty` `.back` `.check` `.chips2` `.addrow` `.toggle` `.group` `.ex` `.go.sm`）。トグルのオンの見た目は、丸が右へ移って白、下地 `--shu-on-ai`。不要になった v4 のクラス（`.exdots`、`.sheet.adjust`、ホームの `.sub`）の CSS は消す。

## 11. 合格条件
- 見本どおり（CSS の数値をそのまま）。全画面を撮って見本と比べる
- 主ボタン `.go` は画面の下半分にあり、`.tabs` は画面の最下部に接している。画面はスクロールしない（390×844、360×640）
- 紙の上の押せるものは `.ln` `.rec` `.ex` `.pill` `.back` だけ（e2e で確かめる）
- `npm test` と `npm run e2e` が通る
