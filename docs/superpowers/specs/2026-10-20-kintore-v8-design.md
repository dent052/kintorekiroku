# 筋トレ記録アプリ 設計書 v8（いつでも終われる・好きな種目へ・その場で自己ベスト）

日付: 2026-10-20 / 状態: 承認済み（利用者「3はいらない、あとはやって」。画面イメージ `docs/mockup-v11.html`）
前提: v7 を土台に、**ここに書いたところを置き換える**。参考：`docs/research/2026-10-20-reference-apps.md` §2。v7 §0（記録を歪めない）は引き続き最優先。

## 1. トレーニング画面の上の段 `.tr-top`
- 左 `.prog`（ボタン、高さ 44px 以上）：進み具合の線と `{n} / {m}`（休憩中は v6 のまま `・ {k}セット目へ` が続く）、最後に小さく `▾`。押すと §2 の種目の一覧
- 右 `.end`：`終了`（白地に藍の枠の丸いボタン、見本の CSS）。押すと §3
- 紙の上で押せるもの（e2e の原則テストの許可リスト）に `.tr-top .prog` と `.tr-top .end` を加える

## 2. 種目の一覧（シート、見出し `今日の種目`）
- 今日のトレーニングの種目を順に `.jl`（ボタン）：左に種目名と小さな状態（済み＝`済み`、今の種目＝`いまここ`、それ以外は無し）、右に `{済んだセット数} / {予定数}`（済み＝済んだ数 ≥ 予定数、朱。今の種目は白）。押すとその種目へ移ってシートを閉じる
- その下に `＋ 種目を足す`（`.addrow`）：v6 のメモシートにあった「種目を追加」と同じ一覧から選ぶ → 最後に足してその種目へ
- 今の種目に `nextId` があれば `この種目を次の段階へ`（`.addrow` と同じ見た目）：v6 の「次の段階へ切り替え」と同じ動き
- 最下部 `閉じる`

## 3. 終了
- 予定がすべて済んでいる（全種目で済んだ数 ≥ 予定数）：確認なしでまとめへ（v6 の `トレーニングを終える` と同じ）
- 残りがある：シート、見出し `トレーニングを終えますか？`、本文 `まだ {a}種目・{b}セット 残っています。記録したところまで保存されます。`（a＝予定が残っている種目の数、b＝残りのセット数の合計）、主ボタン `ここまでで終える`（→ まとめ。やっていないセットは記録しない）、副ボタン `続ける`（閉じる）
- 下の段 `.nav` の最後の種目の `終了` は廃止（上の段に一本化）。v6 の予定後の主ボタン `トレーニングを終える` は残す

## 4. メモのシート
- 見出し `メモ`。メモ欄と `コーチに送る` の切り替え（`.toggle`、v5 の軽めの日と同じ見た目。オンは丸が右へ白、下地 `--shu-on-ai`）と `閉じる` だけ
- v6 の `種目を追加`・`次の段階へ切り替え`（→ §2）、`トレーニングをやめる`（→ §3）はここから外す

## 5. その場で自己ベスト
- どのセットでも、完了したときに、そのセットの値が**同じ負荷**の過去のすべてのセット（今日のそれまでのセットも含む）の最大を上回ったら自己ベスト。過去にその負荷の記録が無いときは出さない（初めては比べられないので）
- 表示：休憩の紙の結果の帯 `.verdict` を藍（`.verdict.pr`）にして、大きな数字＝今日の値、見出し `自己ベスト`、小さく `これまで {最大}{回／秒}`。1セット目の結果（突破など）と同時のときは自己ベストを優先し、小さな文字の後ろに ` ・ ライン突破` などを足す
- 振動 `navigator.vibrate([80, 60, 160])`
- 判定は記録した実際の値だけで行う（v7 §0）。`logic.js` に純粋な関数として置き、テストを足す

## 6. 記録の一覧の大きな数字
- v5 §5 の `.rec` の右の大きな数字を、**前回の1セット目の実際の値**（time は `秒` を付けない）に変え、その下に小さく `ライン {値}`（無ければ出さない）。見本 `.rec .num small`

## 7. 合格条件
- 見本 `docs/mockup-v11.html` どおり
- どの種目からでも `終了` でまとめへ行け、やっていないセットが記録されない
- 一覧から好きな種目へ移れる、種目を足せる
- 自己ベストは同じ負荷の過去の最大を超えたときだけ出る（e2e で境目：同じ値では出ない、1多いと出る、負荷が違えば出ない）
- `npm test` と `npm run e2e` が通る
