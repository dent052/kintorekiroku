# 筋トレ記録アプリ 設計書 v10（アイコン・図と挿絵）

日付: 2026-10-23 / 状態: 承認済み（利用者「アイコンは4（案D）だけど少し色味が暗すぎる」「ほかといっぺんに」。色は Claude が D1 に決定。見本 `docs/mockup-v14.html`・`docs/mockup-v15.html` の D1）
前提: v9（§4.1 含む）を土台に、**ここに書いたところを足す・置き換える**。v7 §0（記録を歪めない）は引き続き最優先。

## 1. アプリのアイコン（Claude が用意する。Codex は触らない）
- 案D1：地 `#2F4C8F`、棒 白、重り `#FF6A4D`。`icon.svg`（any、角丸）と `icon-maskable.svg`（四角の端まで塗る、印は中央の直径80%の円の中）、PNG `icon-192.png`・`icon-512.png`・`icon-maskable-512.png`
- manifest は any と maskable を別々に登録（`"any maskable"` 1枚はやめる）。`sw.js` の `APP_FILES` に足し、`CACHE_NAME` を `kintore-v2` に

## 2. 部位の印 `.pi`（見本 `.pi`）
- 小さな体の図（見本の `body()` と同じ形・同じ座標）を 34px の丸（`#E9ECF1`）の中に置く。その種目の部位だけ朱 `#D03C22`、ほかは `#B4BDCC`、頭は `#DDE2EA`。背中の種目は後ろ向きの図、それ以外は前向き。`全身` はすべての部位を朱
- 置く場所：ホームの種目の行（`.ln.tap` の頭、見本 `.ln.tap.icon`）、記録の種目の行（`.rec` の頭、見本 `.rec.icon`）、トレーニングの種目名の下（`.tag2`：小さな印＋部位名）
- 図は飾りなので `aria-hidden="true"`

## 3. トレーニングの体の図
- 種目名の右に体の図（64×100、見本 `.exhead`）。その種目の部位だけ朱。背中は後ろ向き

## 4. 記録の「今週の部位」
- 記録（種目ごと）の `.seg` の下、種目の行より上に `.bm-card`：見出し `今週の部位（セット数）`、前向きと後ろ向きの体の図、右に一覧 `.legend`
- 数＝今週（月曜はじまり）の部位ごとのセット数（`weekStats(state, today).partSets`、記録したセットをそのまま数える）
- 図の濃さ：10以上 `#1C2B4B`、6〜9 `#4A5C82`、1〜5 `#8FA0BF`、0 `#DDE2EA`
- 一覧：胸・背中・脚・肩・腕・体幹を、多い順（同数は この順）。0 の部位は朱の文字（`.low`）。`全身` は1以上のときだけ一番下に足す（図の濃さには入れない）
- 記録が1件も無いときは出さない（今の空の画面のまま）

## 5. まとめ
- 種目の行 `.sumrow.st`：1セット目がラインを突破した種目（`firstSetResult(...).kind === 'clear'`、v7 のまま）の右に朱の判子 `.stamp`（`突` 改行 `破`）。突破していない種目には何も出さない
- 種目の下に `.bm-card`：見出し `今日きたえた部位`、前向きと後ろ向き。今日記録した部位を藍 `#1C2B4B`、ほか `#DDE2EA`
- 見出しは今のまま `今日の記録`

## 6. コーチの丸
- タイムラインとホームのカードのコーチの丸 `.av`（`コ`）を、アプリのアイコン（§1 の D1 を丸く切った図、見本 `.mark`）に。自分 `私` は今のまま

## 7. 空の画面の挿絵
- コーチの空の画面と記録の空の画面の `.empty` の上に、見本 `.illo` の線画（藍の線、バンドだけ朱）。記録の空の画面は吹き出しを除いた図

## 8. 合格条件
- 見本 `docs/mockup-v14.html` どおり
- 部位の印・体の図は、その種目の部位だけ朱（背中は後ろ向き）
- 今週の部位の数がセット数どおり（e2e：部位ごとに数えた値と一覧が一致、0 は朱）
- 判子は突破した種目にだけ出る（e2e：突破と未達の両方）
- 原則テストが通る（図・挿絵はボタンではない）。`npm test` と `npm run e2e` が通る
