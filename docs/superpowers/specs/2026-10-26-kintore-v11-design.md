前提: v10 を土台に、記録タブ（種目ごと・日ごと）を**置き換える**。v7 §0（記録を歪めない）は最優先：すべての数字・線は記録した実際の値。

## 1. 種目ごと
- 上から：`記録` 見出し、`.seg`、今週の部位（§1.1）、種目のカード `.xc`（記録のある種目、今の順）、体重のカード（§1.3）、`12週間`（今のまま）
- 記録が1件も無いときは今の空の画面のまま

### 1.1 今週の部位 `.bm2`（v10 §4 を置き換え）
- 1段のカード：見出し `今週の部位（セット数）`、左に前向き・後ろ向きの小さな図（38×60）、右に3列の一覧（胸・背中・脚・肩・腕・体幹を多い順、同数はこの順。0 は朱 `.low`。`全身` は1以上のときだけ最後）。数え方・濃さは v10 §4 のまま

### 1.2 種目のカード `.xc`（ボタン。押すと今と同じ詳細へ）
- 1段目 `.xh`：部位の印 `.pi`、種目名（1行、はみ出しは `…`）、`›`
- 2段目 `.xs`：3つの欄を区切り線で横に並べる。見出しは小さく、数字は同じ大きさ（38px、等幅）
  - `負荷`：最新の日の1セット目の負荷。weight＝`{kg}` と小さく `kg`、band＝バンド名（和文の太字 24px）、reps・time＝`自重`（同じ見た目）
  - `1セット目`：最新の日の1セット目の値と小さく `回`（time は `秒`）
  - `次のライン`：`line(state, id, today).value`（朱）。無ければ `—`
- 3段目：グラフ `.spark`（横幅いっぱい、高さ 44）：`setHistory` の各日の1セット目の値を古い順に最大12点、線で結ぶ。最後の点は朱の丸。**前の日より負荷が上がった日**には縦の点線と、その上に `+{差}kg`（weight）または `{バンド名}`（band）。記録が4日未満なら線は描かず `.few`：`記録 {n}回 ・ 4回から線で伸びを描く`
- 4段目 `.xp`：`前回 {最新の日のセット}`（今の `appendSetHistory`）` ・ {今日／昨日／n日前}`、突破が1回以上なら ` ・ 突破 {n}回`。最新の日と、その前の**同じ負荷**の日の1セット目の差が0でなければ灰色の札 `em`：`+2回`／`−1回`（time は秒。下がっても同じ灰色）。前の日より負荷が上がったなら `負荷アップ`
- 今の `.rec` の行（大きな数字・小さな線）はやめる

### 1.3 体重のカード
- `.xc` と同じ形：名前 `体重`、`.xs` は `最新`（{kg} と小さく `kg`）・`7日平均`（{kg}）の2欄、`.spark` は体重の線（4件未満は `.few`：`記録 {n}回 ・ 4回から線で伸びを描く`）。押すと今と同じ体重の詳細へ

## 2. 日ごと
- 見出しの右に `＋ 過去の日`（`.pill.add`、今の「過去の日を記録」と同じ動き）。今の全幅の `＋ 過去の日を記録` はやめる
- `.cal`：今日の月のカレンダー（押せない、見るだけ）。見出し `{年}年{月}月`、右に `やった日 {n} ・ 休み {m}`（その月の、セットのある日の数と休みの日の数）。月曜はじまり。セットのある日＝藍 `.d`、休みだけの日＝斜線 `.r`、今日＝朱の枠 `.t`（やった日なら藍の上に朱の枠）
- その下に日のカード。新しい順。月が変わるところに小さな見出し `.mo`：`{月}月`（今日の月も出す）
- セットのある日 `.dc`（ボタン。押すと今と同じ日のシート）：左 `.dd` に大きな日付（数字）と曜日、右に `.top`：`{n}種目 ・ {m}セット`（軽めの日は後ろに ` ・ 軽め`、同じ日に休みもあれば ` ・ 休み`）、その下に種目ごとの行 `li`：左に種目名（1行 `…`）、右に等幅の値（負荷があれば小さく `15kg`・`Heavy` を前に、続けて `13・10・7`。今の `appendSetHistory` と同じ値）。その日のメモがあれば下に `.memo`（1行目だけ）
- 休みだけの日 `.rest`（ボタン、今と同じ動き）：細い1行 `{日} {曜}・ 休み（{理由}）`
- 体重だけの日：`.rest` と同じ細い1行で `{日} {曜}・ 体重 {kg}kg`

## 3. 合格条件
- 見本 `docs/mockup-v16.html` どおり（文字・数字は実データ）
- 種目のカードの負荷・1セット目・ライン・差の札が記録どおり（e2e：weight・band・reps・time、4日未満は `.few`、負荷を上げた日に点線とラベル）
- 日ごと：カレンダーのやった日・休み・今日、カードの種目数・セット数・値が記録どおり。カードと休みの行から今と同じシートが開く
- 原則テスト（紙の上で押せるものの許可リストに `.see .xc` `.see .dc` `.see .rest` `.see .pill` を含める）。`npm test` と `npm run e2e` が通る
