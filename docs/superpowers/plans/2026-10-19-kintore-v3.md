### Task 1: logic for v3
**Files:** `logic.js`, `logic.test.js`
- `lineHistory(data, exerciseId) => {date, value, load}[]` — for each distinct session date that has the exercise (light included? **no: light=false only**), date ascending, the `line(data, id, date)` value when it has one, with the load of that day's first set.
- `clearCount(data, exerciseId) => number` — sessions (light=false) whose first set is `clear` against `line(data, id, session.date)`.
- `weekHeat(data, today) => number[12]` — days with a session per Mon–Sun week, oldest first, last = this week.
- `menuExercises(data, menu, today) => string[]` — exercise ids for `menu` `{kind:'same'}` (latest non-light session before today, set order, distinct, existing exercises only), `{kind:'template', templateId}` (template ids that exist), `{kind:'custom', exerciseIds}`. Missing/unknown menu → `same`; if that is empty → `[]`.
- Tests for each (including light excluded, unknown template → same, empty data → []).
