### Task 1: accuracy (spec §1, §2)
**Files:** `logic.js`, `logic.test.js`, `app.js`, `style.css`, `e2e/app.test.mjs`
- e2e: band exercise with a 20-rep previous first set starts with the same band and shows `前回20回以上。…を検討`; first-set counter starts at the previous first-set value with no vermilion and no `突破` until 完了; changing the band before 完了 gives `新しい負荷`, and clearCount/feed do not count it; detail chart circles equal the stored first-set values and grey dots equal the other sets, the line breaks at a load change; reload during training (incl. rest) → `続きから` restores exercise, set and rest; a failing `localStorage.setItem` on 完了 keeps the set count and shows the toast.

### Task 2: input and history (spec §3, §4)
**Files:** `app.js`, `style.css`, `e2e/app.test.mjs`
- e2e: tapping the big number gives a numeric input, Enter commits with clamping, Esc cancels, kg accepts 12.5; `日ごと` lists days newest first with per-exercise sets and remembers the choice; `＋ 過去の日を記録` → yesterday → `＋ 種目を足す` → set saved with that date; day sheet `＋ セット` and in-sheet editing; body list edit and delete with `元に戻す`; summary rows per exercise with `前回` and `自己ベスト`, no `合計回数`.
