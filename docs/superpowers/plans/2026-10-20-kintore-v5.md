## Global Constraints
- Files: keep the existing set (`index.html` may get the `nav.tabs` element). No new dependencies, no build step. `logic.js` / `logic.test.js` untouched.
- Data format, GitHub sync, posts, line logic unchanged. Only new storage key: `kintore:light` (spec §4).
- Spec v5 §1 principles are hard rules. Training/rest/summary/counter behave exactly as now.
- Tab icons and the pencil icon: the inline SVGs from the mockup, `aria-hidden="true"`, with visible text.
- Principle test scope (decided): the indigo `.see.slab` screens (settings and the editors) are exempt from the `.see` pressable whitelist, as in v3. The "`.go` in the lower half" rule applies only to the `.go` inside `.press`; buttons inside the settings/editor content (e.g. GitHub 保存's save) stay where v3 puts them.
- Japanese copy exactly as the spec says.
- `npm test` and `npm run e2e` green at the end of every task. e2e tests for removed UI (今日の調整 sheet, growth mode, growth swipe/dots/nav, settings bottom row, the old principle rule "nothing pressable on the paper") are replaced in the task that removes them; all other existing e2e assertions keep their meaning (only selectors/labels the spec renames may change).
