## Global Constraints
- Files: keep the existing set. No new files except tests where stated, no new dependencies, no build step.
- Data format, storage keys, GitHub sync, posts, line logic unchanged. `logic.js` / `logic.test.js` are not touched in this plan.
- v3 principles still hold: every pressable control is inside `.press`, a `dialog.sheet`, or the settings slab; the page never scrolls (only `.see`).
- Keep `data-mode` values (`today`, `growth`, `train`, `summary`, `settings`). The home is mode `today`.
- The home icon is the inline SVG from the mockup (`<svg viewBox="0 0 16 16" ...><path d="M2 8 8 2.5 14 8M4 7v6.5h8V7"/></svg>`), `aria-hidden="true"`, button text `ホーム`.
- Japanese copy exactly as the spec says.
- `npm test` and `npm run e2e` green at the end of every task. e2e tests for removed UI (pager, today⇄growth swipe, growth chips, ruler) are replaced in the task that removes it; all other existing e2e tests keep their assertions (only selectors/labels that the spec renames may change).
