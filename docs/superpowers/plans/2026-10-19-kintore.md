# 筋トレ記録アプリ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution in this project:** each task is handed to Codex (`codex exec`) by Claude. Codex implements exactly what the task says. **If anything needs a decision the plan and spec do not make, Codex stops, writes the question to stdout, and does not guess.** Claude reviews every task's diff and runs the verification before the next task.

**Goal:** A single-user PWA for logging bodyweight / band / timed / weighted workouts that shows progress, gives next-session advice, and backs up to a private GitHub repo that a weekly Claude task reviews.

**Architecture:** Static files at the repo root served by GitHub Pages. All decision logic lives in pure functions in `logic.js` (tested with `node --test`); `app.js` renders four tabs, owns `localStorage`, timer and GitHub sync. No build, no framework, no npm dependencies.

**Tech Stack:** HTML, CSS, JavaScript ES modules, `node --test` (Node 22), Service Worker, GitHub REST API.

**Spec:** `docs/superpowers/specs/2026-10-19-kintore-design.md` (Japanese). Visual reference: `docs/mockup.html` theme A (dark × orange).

## Global Constraints

- Files (repo root only): `.nojekyll`, `index.html`, `style.css`, `app.js`, `logic.js`, `logic.test.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `coach/README.md`. Create no other app files.
- No dependencies, no build step, no frameworks, no chart library. Only external resource: Google Fonts Barlow Condensed 500/600/700.
- `logic.js` never touches DOM, `localStorage`, `fetch` or `Date.now()` implicitly — "today" is always a parameter.
- Dates are local `YYYY-MM-DD` strings. Never derive them from `toISOString()` (UTC shifts the day before 09:00 JST).
- Storage keys: `kintore:data`, `kintore:github`, `kintore:feedback`. The token lives only in `kintore:github` and is never exported or synced.
- `index.html` has `<meta name="robots" content="noindex, nofollow">`, `lang="ja"`.
- UI text is Japanese and exactly as written in the spec where the spec gives it. Never blaming on rest days.
- Colors (CSS custom properties on `:root`): `--bg #1F2937` `--card #313742` `--muted #37414F` `--fg #F8FAFC` `--fg2 #CBD5E1` `--line #374151` `--primary #F97316` `--on-primary #0F172A` `--accent #22C55E` `--danger #EF4444` `--coach #26303d` `--advice #3a2a1f` `--timer #111823` `--tabbar #1A2330`.
- Tap targets ≥ 48×48px, gap ≥ 8px; set value 48px, timer 64px, body ≥ 16px; numbers in Barlow Condensed; icons inline SVG, no emoji; motion 150–250ms and none under `prefers-reduced-motion`.
- Defaults: exercise `min/max` 8/15 (time 20/60), `weeklyGoal` 3, `restSec` 90, weight default 5 kg, steps reps ±1, sec ±5, kg ±0.5, body weight ±0.1, waist ±0.5.
- Comment only the why. Required shortcut comments (verbatim): `// shortcut: localStorage は約5MB上限、10年分程度で IndexedDB へ移行` and `// shortcut: 単一端末前提で常に上書き。複数端末で使うなら updatedAt 比較を追加`.

## Review Focus

1. **Late-night / early-morning dates** — a set logged at 01:30 JST belongs to that local day, not the previous UTC day. Test in Task 1 (`localDate`).
2. **Corrupt or full storage** — unparsable `kintore:data` must not be silently replaced by empty data; a failed save (quota) must show an error, not lose the set. Covered in Task 4 (`loadData` keeps the raw text under `kintore:data:broken`).
3. **Bad import file** — importing a non-JSON or wrong-shape file must leave current data untouched. Test in Task 3 (`parseImport`).
4. **Large Japanese payload to GitHub** — base64 of a multi-MB UTF-8 string must not throw (spread-argument limits). Test in Task 3 (`toBase64Utf8`).
5. **Archived exercises** — history, totals, compare and `nextId` targets still resolve archived exercises by id; only pickers hide them. Test in Task 2 (`totals` includes archived).

**Interfaces:**
